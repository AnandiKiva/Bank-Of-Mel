# 💜 Bank of Mel — Multi-Page Banking Demo App

A clean, modern **desktop banking UI** inspired by the Bank of Mel Figma prototype.  
Built entirely with **HTML, CSS, and JavaScript** — no frameworks required.

This app simulates a basic banking system with:

- Create Account  
- Deposit  
- Withdraw  
- Balance  
- Transaction History  
- Account Details  
- LocalStorage Persistence  
- CSV Export  
- Multi-Page Routing  
- Gradient UI styling  

> ⚠️ This is a **frontend-only demo**.  
> No real money, backend, or authentication is used. All data is stored locally in your browser.

---

## ✨ Features
### 🔹 Multi-Page Layout  
 Each page is an individual `.html` file:
- index.html → Create Account
- deposit.html → Deposit Money
- withdraw.html → Withdraw Money
- balance.html → View Account Balance
- history.html → Transaction History
- details.html → Account Details & Delete


### 🔹 Local Storage Persistence  
All accounts and transactions are stored in your browser and survive page refreshes.

### 🔹 CSV Export  
You can export:
- Full transaction history  
- Individual account transactions  

### 🔹 Beautiful Bank-Style UI  
Styled using:
- soft lavender backgrounds  
- purple gradients  
- rounded cards  
- clear typography  
- subtle shadows  
- icons matching the Figma look  

### 🔹 No Dependencies  
✔ HTML  
✔ CSS  
✔ JavaScript  
✔ Works offline  
✔ No build tools needed
